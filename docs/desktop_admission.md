# Desktop benchmark admission

Home provides Pause new benchmarks independently from Stop listener. It calls only fixed packaged sidecar admission commands with the same config directory as the listener. The toggle keeps its last confirmed preference while waiting; duplicate requests coalesce. Errors preserve the prior value, announce that saved state is unconfirmed and move keyboard focus to Refresh. Pairing repair guidance has priority. Pausing before connection is a saved local preference, never a connection claim.

Native control output is limited to the exact admission schema and boolean, with a 4096-byte capture limit and 45-second supervised deadline. Helper ownership and app work/operation fences remain until its own event stream acknowledges termination. Kill failure is explicit; lost acknowledgement retains the fences. Unix sidecars exec Python in place; Windows sidecars use the existing kill-on-close job containing Python. No active listener or benchmark is stopped.

Validation: 60 native tests passed (two opt-in ignored), including closed projection and cleanup acknowledgement/lost-channel scenarios; Clippy passed. 75 desktop tests and Vite build passed before integrating other desktop result changes. Four compact Home captures at 1060×900/375px, light/dark, were inspected without horizontal overflow through a scoped command adapter. Keyboard Space pending confirmation, confirmed pause, failure rollback, and focus to Refresh passed; adapter browser closed. These are source, protocol and browser checks, not installed native GUI/OS-keyring or production-account acceptance. Exact integrated full-suite counts are recorded in delivery receipts.
