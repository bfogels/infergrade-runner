# Desktop private local benchmarks

Found on this machine retains its engine check and adds **Benchmark privately**.
Choose a local GGUF, use case and canary/standard depth in Models. This calls the
canonical `benchmark-local` command with the currently selected installed CLI
and server; no Hub run identity, upload handoff, keyring token or HF credential is
provided. Missing runtime binaries require repair rather than a silent selection.

Stop listening and finish active work before starting. Native exclusive work
admission prevents overlap with other desktop work or cache maintenance. The
supervisor retains the exact child PID and lifecycle/cache guard until matching
termination. Stop targets that PID; a lost event channel or failed Stop keeps
ownership and the exit fence. Fixed phase/count progress appears on Home;
arbitrary process stderr is discarded. Unix SIGINT lets the canonical pipeline
stop its model server and retain a failed local report. Windows terminates the
child tree; an unacknowledged local receipt remains unfinished.

Activity lists private reports separately from Hub jobs. Empty history creates
no storage. The reader scans at most 10000 entries, validates closed bounded
receipts, and loads at most the newest 50 result records. Identity mismatch,
linked/nonregular files, invalid scalar states and malformed deeply nested JSON
are excluded with an unreadable-count warning. Components remain visible when
canonical headline-score readiness is false; no chart point is manufactured.
Reports open only the fixed local report for an available validated private ID.

History helper output is capped at 512 KiB and 30 seconds. Failures/timeouts retain
cleanup supervision until child termination is acknowledged. Private child
process environments contain an OS/runtime allowlist, with no Hub/HF credentials,
proxy variables or inherited PYTHONPATH. Trusted source/evaluator overrides are
limited to development builds.

UI requests coalesce, stale polls/history cannot replace a newly started process,
Stop errors appear on Home, and history refresh preserves focused report actions.
Native work and browser replay are different acceptance stages. Installed Mac
GUI execution/report opening remains unverified while the host is locked.
