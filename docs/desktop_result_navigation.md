# Desktop accepted-result navigation

Activity loads accepted results only when the user selects View results on a completed job. It offers each result separately, preserving its deployment profile and full scoring denominator. Hub-authoritative qualified results offer Show my data point; unavailable or unknown qualification offers Open report. Native commands verify completed status and exact machine targeting before reading the owner-scoped result association, then reject a changed paired identity or credential. Navigation accepts only bounded closed fields and exact source bindings; it never trusts a server-provided external URL.

Keyboard focus remains on the exact run/action/result after polling or result refresh. Loading retains the focused control with aria-busy, and concurrent requests coalesce. Disconnect clears cached results and generation fences discard late responses.

Exact Show my data point focus survives Activity refresh and keyboard Enter dispatches the bound paired-Hub URL.
